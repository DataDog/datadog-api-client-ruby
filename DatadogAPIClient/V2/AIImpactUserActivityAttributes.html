Overview

Daily AI coding tool activity for a single user. Each entry reports whether the user was active on a given day and which AI tools and models they used.

Instance Attribute Summary collapse

  • #day ⇒ Object readonly

    The day the activity refers to, in YYYY-MM-DD format.
  • #is_active ⇒ Object readonly

  • #models ⇒ Object

  • #tools ⇒ Object readonly

    The AI coding tools the user used on that day, for example Claude Code, Cursor, or GitHub Copilot.
