Overview

A message in the conversation. Content is required for user, system, developer, and tool messages, but may be omitted for assistant messages. For those non-assistant roles, a plain content string may be empty, but a multipart content array must contain at least one valid content part. Only assistant messages may contain tool calls, and tool call entries must not be null. Tool messages must include a non-empty tool_call_id; other message roles must not include a non-empty tool_call_id.
