List Agent Health issues.

List Agent Health issues across your organization. Only open issues are returned. Returns 403 if you lack the hosts_read permission.

Results use a stable order: severity rank (high, medium, low, then other values), then first_seen_at descending with missing timestamps last, then issue ID ascending. Use page[size] and the zero-based page[number] to paginate. Invalid page values return a 400 JSON:API error response. meta.page.total_filtered_count is the number of issues matching the filters, and meta.page.total_count the number of open issues in the organization.

Each filter accepts up to 50 comma-separated exact values of at most 256 characters each, combined with OR within a filter and AND across filters. Blank entries are ignored; an all-blank filter is treated as absent.

Parameters:

  • opts (Hash) (defaults to: {}) —

    the optional parameters

Options Hash (opts):

  • :page_size (Integer) —

    The number of issues to return per page, from 1 to 100. Defaults to 25.

  • :page_number (Integer) —

    The zero-based page number, from 0 to 1000000. Defaults to 0.

  • :filter_severity (String) —

    Filter by a comma-separated list of exact severity values, up to 50 values of at most 256 characters each. Values are combined with OR within this filter and AND across filters. Blank entries are ignored; an all-blank filter is treated as absent.
