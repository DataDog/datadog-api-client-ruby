Overview

RUM application creation attributes. When rum_event_processing_state is omitted, it defaults to ALL. When product_analytics_retention_state is omitted, Product Analytics is not enabled. Setting it to MAX requires the product_analytics_apps_write permission.

#create_default_retention_filters ⇒ Object

Whether to create the default retention filters when the application is created: Sessions with errors and Sessions, each with a 100% retention rate. Set to false to create the application without them, for example when you add your own retention filters right after creating it. Until you add retention filters, the application only retains sessions matched by its permanent retention filters. This setting doesn't affect permanent retention filters (sessions with forced replays, Synthetics sessions and RUM-APM flat sampling).
